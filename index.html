关联图（Interrelationship Digraph）

亲和图 · KJ 法（Affinity Diagram）

DMADV / IDDOV · DFSS 六西格玛设计路线

DMAIC 是把已有的过程改好，DFSS 是从一开始就把质量设计进去。当现有产品改到极限仍达不到顾客要求、或者这是一件从没做过的新东西时，继续用 DMAIC 只会得到一堆「改不动」的结论。DMADV（Define-Measure-Analyze-Design-Verify）与 IDDOV（Identify-Define-Develop-Optimize-Verify）是两条通行的 DFSS 路线，本模块给出每阶段的目的、活动、工具、交付物与 Gate 门槛，并实时算推进完成度。

Gate 门槛项勾选后自动保存在本机浏览器。当前阶段的门槛没过就往下走，是 DFSS 项目后期大规模返工的头号原因——设计阶段省下的两周，会在验证阶段变成两个月。
使用声明：本模块为 DFSS 路线框架与阶段推进跟踪的辅助工具，各公司 / 咨询机构对阶段划分、Gate 门槛条目与命名存在差异（如 DMADV 亦有称 DMADOV、DCCDI 等变体），须以本组织的设计开发程序文件与实际顾客要求为准。

ISO 9001 条款自查

质量成本 COQ

把质量从「感觉」翻译成「钱」。COQ 把质量相关支出拆成预防、鉴定、内部失败、外部失败四类，让你能用一张表跟老板讲清楚两件事：质量部门不是花钱部门，而是堵漏部门；以及这笔钱下一步该往哪儿花。典型用途：年度质量预算答辩、改善项目立项算经济账、向客户或供应商谈质量责任时的成本论据。 注意口径：不同企业对返工工时、停工损失、信誉损失是否计入差异极大，本工具按通用四类模型处理，横向对比前必须先确认口径一致。

① 预防成本 Prevention

科目金额（元）
小计：—
为「第一次就把事做对」花的钱：质量策划、培训、供应商开发、设计评审、防错装置。这类钱花得越少，后面三类通常越多。

② 鉴定成本 Appraisal

方针管理 Hoshin

Hoshin Kanri（方针管理 / 方针展开）解决的不是「怎么做计划」，而是那个老毛病：经营层喊的目标和车间干的事对不上。它用一张 X 矩阵把「中长期方针 → 年度目标 → 改进方策 → 责任人」垂直串起来，谁跟谁有关系、谁在挂空挡，一眼看得见。 核心是接抛球（Catchball）：目标不是压下去的，是上下反复对齐、讨价还价、争出来的；矩阵的价值是暴露上下不一致，不是做一张好看的计划表。

关于 X 矩阵的画法：X 矩阵的象限方位在不同资料与咨询机构中存在多种画法（常见差异：中长期方针放在下方还是右侧、方策放在顶部还是右侧、中心格放责任人还是放指标）。本工具采用其中一种通行画法：左上「年度目标 × 改进方策」、右上「改进方策」、左下「年度目标」、右下「中长期方针目标 × 年度目标」。这不是标准规定，跨公司对齐时请先统一画法再讨论内容。

⑤ Catchball 接抛球记录

议题（争议点）提出方反馈方结论 / 修订意见状态

看板 / 拉动计算

推动式生产是「我做了你就得接着」，拉动式是「你用完我才补」——看板就是拉动的信号物。核心公式：看板张数 N = ceil( D × L × (1+α) ÷ C )。本模块帮你算需要多少张看板，并解释 D（日需求）、L（补货周期 / 提前期）、α（安全系数，默认 0.1 即 10% 经验值）、C（容器容量）各自的含义，以及为什么必须加安全系数。

使用声明：看板张数为理论计算值，未考虑需求与提前期的波动分布、容器周转损耗与换班衔接；实际投放须结合现场节拍与缓冲由具备资质的人员核定。
